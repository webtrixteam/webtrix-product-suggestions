# webtrix-product-suggestions
WooCommerce plugin that shows suggested products with live prices on the single product page and lets customers add them to the cart in one click. Per-product lists, global category rules, list/grid/carousel layouts, RTL, Persian &amp; English.

افزونهٔ ووکامرس برای نمایش محصولات پیشنهادی با قیمت زنده در صفحهٔ محصول و افزودن سریع آن‌ها به سبد خرید. لیست اختصاصی هر محصول، قوانین سراسری بر اساس دسته‌بندی، مدل‌های لیست/شبکه‌ای/اسلایدر، RTL، فارسی و انگلیسی.
